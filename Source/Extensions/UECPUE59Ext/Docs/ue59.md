# `ue59` — Unreal Engine 5.9 agentic stack

UE 5.9 (MegaJam Preview, Nov 2026) makes the editor an agent host:

- The **Unreal MCP** server starts together with the editor.
- Dozens of new **Toolset Registry** toolsets ship with the engine.
- **Markdown Agent Skills** are discovered automatically.
- **Unreal Assistant** runs Claude Code, Codex, Cursor or OpenCode in an editor panel.

Almost every one of these plugins is **Experimental**. Start with `ue59_feature_status`. Never say a feature worked when its plugin is disabled.

| Need | Tool |
|---|---|
| What is enabled (per preset), toolset/tool counts, Axivor toolset, skills found | `ue59_feature_status` |
| Turn a group of plugins on (restart required) | `ue59_enable_preset(preset)` |
| List / read Agent Skills (engine, plugins, project) | `ue59_skills(action='list'\|'read', key?)` |
| Native MCP settings and coexistence with Axivor | `ue59_mcp_status` |
| Call any native toolset in-process | `engine_list_toolsets`, `engine_describe_toolset`, `engine_call_tool` (`engine` umbrella) |

## Presets (`ue59_enable_preset`)

- `agents` — the base agent host:
  - `ModelContextProtocol`, `ToolsetRegistry`, `AllToolsets`, `FileSandbox`
  - `KnowledgeBase` + `KnowledgeBaseToolset`
  - `AgentCapability` + `AgentPluginToolset`, which read Claude/Codex agent plugins and `CLAUDE.md`/`AGENTS.md`
- `blueprint_dsl` — `GraphDsl` + `BlueprintToolsets`. Reads and writes whole Blueprint graphs as S-expressions; good for large rewrites.
- `debug_perf` — `ConsoleToolset`, `CheatsToolset`, `PerfToolset`, `RewindDebuggerToolset`, `SlateDebugger`, `WidgetFinder`, `SceneCaptureToolset`, `MediaToolset`, `NavMeshToolset`.
- `ui` — `WidgetAnimationToolset`, `WidgetStaticAnalysisToolset`, `CommonUIToolset`, `InputToolset`.
- `canvas` — Unreal Canvas: `UnrealCanvasBridge` (exposes Movie Render Graph as MCP tools), `UnrealCanvasGraph`, `UnrealCanvasAnnotations`. Image, video and mesh generation runs on the user's own API keys.
- `animgen` — `UAFAnimGen` (AnimGen for UAF), `AnimGenOffline` (generated animation in Sequencer), `Kimodo`.
- `metahuman_agents` — `AllMetaHumanToolsets`.

Known issue UE-412135: in new projects the toolset plugins start disabled. Run `ue59_enable_preset('agents')`, which enables `AllToolsets`, then restart the editor.

## Axivor inside Unreal MCP / Unreal Assistant

Axivor registers a native toolset named **`Axivor`** in the engine registry. Agents connected to the engine's MCP server (`:8000`) or running in Unreal Assistant can call:

- `Axivor.SearchTools(query)`
- `Axivor.GetToolDocs(category, action?)`
- `Axivor.CallTool(tool, arguments)`

These calls go through Axivor's pipeline, so the interaction mode, crew permissions and destructive confirmations apply. To turn this off, set `ExposeToEngineToolsetRegistry=False` in the `[BpGeneratorUltimate]` section. With tool search on (the engine default), clients see only the four engine meta-tools and reach Axivor through `call_tool(name='Axivor.CallTool', ...)`.

The plugin ships the skill `/Skills/BpGeneratorUltimate/axivor-editor-tools`, which teaches external agents this workflow.

## Port and porting notes (5.8 → 5.9)

- **Ports:** Axivor's own MCP server listens on `:30000`–`30009`, and Unreal MCP on `:8000`. They do not collide.
- **Cascade:** it is a plugin now (`Cascade`, module `CascadeRuntime`). `UParticleSystem` still loads.
- **Removed plugins:** `UMGToolSet`, `SemanticSearchToolset` and Python Foundation Packages. Semantic search now lives in the Knowledge Base, and UMG tools in `WidgetAnimationToolset` / `WidgetStaticAnalysisToolset`.
- **Engine bugs in the Preview:**
  - UE-411502: swapping a Blueprint root from Python can crash.
  - UE-411097: changing a Dataflow pin can crash.

  Avoid both in automated batches. Wrap risky edits in `engine_sandbox`.
